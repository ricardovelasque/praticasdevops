Este site foi desenvolvido utilizando HTML, CSS e pode ser instalado como um aplicativo PWA.

Por que usar PWA?

  • Funciona offline
  • Pode ser instalado no celular
  • Desempenho rápido
  • Notificações e outras funcionalidades modernas

Aplicações progressivas

PWA é um acrônimo para Prgoressive Web Apps, ou Aplicações Web Progressivas. A palavra progressiva vem da ideia de Progressive Enhancement, ou melhoria progressiva. Neste contexto, a ideia por trás da palavra progressiva é condicionar uma aplicação a atender o maior número de pessoas possível, sob todos os aspectos.
